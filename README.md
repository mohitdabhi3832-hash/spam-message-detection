# spam-message-detection
A machine learning-based SMS spam detection system built using algorithms and streamlit for real-time message classification.

# Features
- Detects spam messages instantly
- User-friendly Streamlit interface
- Machine learning-based text classification
- Fast and accurate prediction

# Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit
- pickle

# Machine Learning Model
- Logistic Regression
- SVC
- KNN
- Decision Tree
  
# Dataset
SMS Spam Collection Dataset
